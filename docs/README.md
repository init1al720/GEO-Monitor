## 项目定位

- **监测对象**：品牌在 AI 引擎（DeepSeek / 豆包 / 通义等）回答中的曝光情况
- **核心链路**：问题库 × 引擎 → 采集原始回答 → 提及/位次分析 → 指标看板 → 导出
- **技术栈**：前端 Next.js 16 + React 19 + Tailwind 4 + Recharts（已定，不再改 Vue）；数据层 Supabase（Postgres + Auth + RLS 直连）；后端 Python 采集与分析服务，跑在自有服务器
- **节奏**：4 周 MVP，每周五可演示
