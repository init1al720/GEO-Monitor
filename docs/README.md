## 项目定位

- **监测对象**：品牌在 AI 引擎（DeepSeek / 豆包 / 通义等）回答中的曝光情况
- **核心链路**：问题库 × 引擎 → 采集原始回答 → 提及/位次分析 → 指标看板 → 导出
- **技术栈**：后端 FastAPI + SQLAlchemy(async) + Postgres，前端 Vue 3（React 亦可，页面拆法不变）
- **节奏**：4 周 MVP，每周五可演示

## 里程碑

| 周 | 目标 | 关键交付 |
|---|---|---|
| W1 | 登录 + 项目 + 问题库 | 3 表 / 7 接口 / 4 页面 |
| W2 | 采集链路 | `runs` / `responses` 表、引擎客户端、异步任务与进度轮询 |
| W3 | 提及分析与指标 | `mentions` / `daily_metrics`、看板数据接口 |
| W4 | 定时、导出、上线 | APScheduler、Excel 导出、服务器部署 |
