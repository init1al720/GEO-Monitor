## 项目定位

- **监测对象**：品牌在 AI 引擎（DeepSeek / 豆包 / 通义等）回答中的曝光情况
- **核心链路**：问题库 × 引擎 → 采集原始回答 → 提及/位次分析 → 指标看板 → 导出
- **技术栈**：后端 FastAPI + SQLAlchemy(async) + Postgres，前端 Vue 3（学弟定，React 亦可）
- **节奏**：4 周 MVP，每周五可演示
